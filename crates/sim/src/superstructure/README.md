# `superstructure/` (SuperStructure rooms)

`mod.rs` declares the sub-folders; each has its own file map:

- `projections/`: projected circles, scan lines, stars, the projector.
- `electric/`: light rods, zap coils, fuses, room fixtures.
- `grab/`: screen-grab effects (`DeepProcessing`, `GravityDisruptor`).
- `coral/`: coral neurons, stems, systems, wall mycelia, circuits.
